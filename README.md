# NUXT + Strapi portfolio website

this is a basic nuxt and strapi portfolio boilerplate

# prerequisites

node v20 [lts]

# install

in both folders BE/FE use `yarn`
run strapi with `yarn develop`
run nuxt with `yarn dev`

the Front-end has  a few staticli defined pages and then a set of components custom built for the 'work' collection as this repository is supposed to be mainly an artist portfolio, so the biggest emphasis is given to presenting images of artists artworks.

# Build and CICD
is set up so far only for the Frontend, as the strapi might change its definitions of models while used on the remote, so it could get a bit messy or lead to data loss if CICD was oushing builds there.
